## BL-022 detail: shared gallery and default sources

1. Share saved photographs across all skins of the same student. Resolve membership through canonical student
   identity rather than localized names. Keep each photograph's originating variant, scene mode and stable ID.
   Selecting a photo for one variant must not silently overwrite other variants' App/game selections.
2. Keep two distinct protected defaults visible: the official Collection portrait and the portrait automatically
   generated for the student roster. When no custom choice is saved, use the generated default; the official
   portrait requires an explicit user choice. Preserve deliberate custom selections and existing photographs.
   The generated default follows the relevant portrait source/revision and must not become a stale hidden capture.
3. Treat generated-default selection and explicit game Apply as separate concepts. Resolving an App fallback must
   not silently write game files during launch or gallery browsing. Future generated/default application must obey
   the same desired-state, master-switch, shared-bundle preservation and rollback rules as custom photographs.
   Restore Default should follow the generated-default rule; the official portrait remains a separate choice.
4. Replace the manifest-wide display counter with an independent, persistent counter for each originating variant.
   Capture under skin A must not consume skin B's numbers. Preserve stable IDs and ordering, avoid reusing numbers
   after deletion, and migrate existing galleries without losing images, selections or provenance. Photos from
   another skin use the same localized variant-naming convention as portrait-source selection.
5. Add Export at the gallery's lower left. Export the selected full-quality image to the configured export
   directory, verify successful output, then open that directory in the OS file manager. Preserve PNG quality,
   handle name collisions and failures, and never open a directory as if an export succeeded before publication.

Acceptance includes two unrelated students, several skins of one student, original/generated/custom choices,
cross-skin selection, old-gallery migration, cache clearing, source revision changes and export collisions. Retain
the existing switch-off/deferred-apply and shared-Collection preservation regression coverage.

## BL-023 detail: camera guides, placement and save readiness

1. Add an Occlusion Guide toggle immediately to the left of the grid toggle. When enabled, show the actual
   student-roster lower gray banner and the Exclusive Weapon indicator area over the framing guide, in the same
   relative scale and position as the game. Derive geometry, sprites and anchors from the Collection-card prefab;
   verify both ordinary and weapon-unlocked cases. Do not substitute Tactical Challenge/formation portraits or
   estimate the mask from the camera frame. The overlay must track guide resizing and device pixel ratio 1:1.
2. The guide is composition assistance only. Neither its mask nor any existing camera controls, grid, dialogue,
   pointer/click effects or save animation may enter the saved PNG. Keep the actual rendered portrait/L2D quality.
3. In portrait fullscreen, remove the text beneath Reset. In memorial fullscreen, move the camera entry to the
   position currently occupied by portrait Reset. Preserve consistent icon size and visual centering.
4. An immediate save occasionally reports that the frame is not ready. For a transient readiness race, retain the
   intended scene/expression/action, wait or repair in the background, capture a valid frame and complete the
   existing save/apply flow without that modal. Debounce duplicate captures, cancel stale route/session requests,
   and never publish a blank/stale photograph or claim success before durable storage. Do not hide genuine disk,
   invalid-source or permanent rendering failures behind silent success; use the appropriate existing failure path.

Future verification should cover slow first load, rapid shutter presses, paused/intro memorial scenes, mode
switches and leaving the camera during pending work, in addition to the owner's occlusion/placement review.
