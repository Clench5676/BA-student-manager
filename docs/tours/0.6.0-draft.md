## Owner review decisions

- The two text-only pages and all six copies are included in prereleases for review.
- Stable publication requires the owner's final approval: change `approved: 'prerelease'` to `approved: True`
  in `webui/tours.py`'s `PUBLISHED_TOURS` only after that approval.
- Each page has `id` and six `copy` entries (`title`, `body`). Title/body limits are 80/320 characters.
  Pages without complete copy in all six locales are omitted. Revisions to an already presented release never
  create a new automatic prompt.
