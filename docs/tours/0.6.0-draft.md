## Owner review decisions

- Approve or revise the two pages and all six copies against the final 0.6.0 scope.
- Keep text-only pages, or review completed App UI illustrations and captions before packaging them.
- Publishing a tour is an explicit source change to `webui/tours.py`'s `PUBLISHED_TOURS`, with `approved: True`.
  Each page needs `id`, six `copy` entries (`title`, `body`, optional `caption`) and an optional `/tours/<name>.png`
  illustration in the packaged web directory. The title/body limits are 80/320 characters; image captions fit one
  line and are limited to 40 characters. Missing/invalid images fall back to text. Pages without complete copy in
  all six locales are omitted. Revisions to an already presented release never create a new automatic prompt.
